Privacy Policy — Modern Health

Last updated: 2026-08-19

Modern Health is a personal fitness-scheduling tool. This page describes what data it accesses, why, and how it's stored.

What data is accessed

With your explicit consent via OAuth, the app reads the following categories of health and fitness data from your connected account:

  • Resting heart rate
  • Sleep stages and duration (used to compute a custom sleep-quality score)
  • Activity minutes and exercise history

The app does not request write access to your health data — it only reads it. It does not access location, nutrition, or any other data category beyond what's listed above.

Why it's accessed

This data feeds a personal recovery-score calculation that recommends which of a fixed set of workout types (leg day, upper body, functional training, badminton, pickleball, running) to do each day, based on how recovered you appear to be and how recently you've done each type of workout.

How it's stored

Data is stored in a private Firestore database, scoped to your individual account via Firebase Authentication. Access rules (enforced server-side) ensure only your own signed-in session can read your data — no other user of this software, and no third party, can access it. OAuth tokens used to access your health data are stored in a separate, admin-only location that is never exposed to any client application, including this one.

Sharing

This data is never sold, shared, or used for advertising. It is not transmitted to any third party. It is used solely to compute and display your own daily workout recommendation, to you.

Retention and deletion

Recent daily metrics (roughly the last 21 days) are retained to compute rolling personal baselines. Historical workout and feedback records are kept to personalize recommendations over time. You can request deletion of all stored data at any time by contacting the address below.
